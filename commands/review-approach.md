name: review-approach
description: Review the current implementation approach and suggest improvements
---

Review the current implementation approach:

1. **What was the goal?** Restate the original requirement.
2. **What was done?** Summarize the changes made so far.
3. **Does it solve the problem?** Evaluate whether the implementation actually addresses the
   requirement.
4. **What could be improved?** Identify any issues, missed edge cases, or better approaches.
5. **What's missing?** Are there tests, error handling, or documentation that should be added?
6. **Side effects?** Did the changes break or affect anything else?

Be honest and specific. If the approach is wrong, say so and suggest a better one.
